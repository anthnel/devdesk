  **What is Claude Desktop?**
  Claude Desktop is a separate native desktop application (macOS, Windows, Linux beta) distinct from Claude Code. It runs in three modes—Chat, Cowork, and Code—and provides direct access to local files, screens, and terminals for autonomous agent work.
  
  **Does Claude Desktop support launching agents in sandboxes?**
  No, not in the Docker Sandboxes sense. Claude Desktop has:
  - **Built-in security sandboxing**: Controls filesystem, network, and command execution access via configurable settings—this limits what Claude *can access*, not how agents are *deployed*.
  - **No Docker Sandboxes (`sbx`) support**: Docker Sandboxes are a Claude Code CLI feature only.
  
  **How does Claude Code CLI compare?**
  Claude Code (CLI) offers robust sandboxing:
  - **Docker Sandboxes** (`sbx` CLI): Isolated containerized development environments
  - **Worktree isolation** (Agent SDK): Agents confined to Git worktree branches

  | Feature | Claude Desktop | Claude Code CLI |

  | MCP servers | ✅ | ✅ |
