  ## Objections, de la plus grave à la plus mineure
  
  **1. L'existence d'une API de recherche n'est pas prouvée pour la moitié des registres visés.**
  - **Docker Hub.** La seule recherche stable est celle qu'utilise `docker search` (`index.docker.io/v1/search`). Elle donne nom, description, `star_count` et `is_official`. Elle ne donne ni le nombre de pulls, ni les badges « verified publisher » ou « sponsored OSS ». Ces champs ne sortent que d'endpoints non documentés de hub.docker.com (search v3 / catalog). Docker y déprécie des endpoints régulièrement : `/v2/repositories/{namespace}` le 2025-06-27, d'autres le 2025-09-19.
  - **dhi.io.** Je n'ai trouvé aucun endpoint REST public documenté pour lister le catalogue. Les voies officielles sont le serveur MCP `https://dhi.io/mcp` (outil `dhi_list_repositories`), la CLI `docker dhi catalog list --json` et le catalogue web du Hub. Toutes demandent un compte Docker ou un token.
