# Planning Rules

## Implementation Plans

- **Location**: Always write implementation plans to `.claude/plans/` in the current project directory.
- **Format**: Use Markdown format for plans.
- **Naming**: Use descriptive names like `feature-name-plan.md` or `YYYY-MM-DD-feature-name.md`.

## Antigravity IDE Integration

When using the Antigravity IDE extension:
- Save all implementation plans to `.claude/plans/` relative to the project root.
- Create the directory if it doesn't exist before saving plans.
- Plans should be accessible from both Claude Code CLI and Antigravity IDE.
