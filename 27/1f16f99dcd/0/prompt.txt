Writing is done by:

It validates the name, ensures `~/.devdesk` exists, `yaml.Marshal(cfg)`, writes with mode `0600`. This is exactly the function the setup wizard should call to persist the finished `*Config`.

Also relevant: `config.CreateContext(contextName string) error` (`config.go:900-923`) builds `Default()`, clears `Status.Components` and `Forge.URL`, and calls `SaveContext` — a good template for "scaffold a new context" before the wizard fills in specifics, though the wizard will likely want to build a fuller `Config` itself and call `SaveContext` directly rather than `CreateContext` (which errors if the context already exists — see §7).
